Sign-in token

PawConnect has no sign-in screen in this frontend yet. Protected pages need an Amazon Cognito ID or access token that you obtained from your own Cognito sign-in. The backend verifies it on every request.

The token is kept in memory only. It is lost when you reload the page.
PawConnect · frontend is a thin presentation layer; all rules are enforced by the backend.
